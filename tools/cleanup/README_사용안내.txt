==============================================================
 ITMA tools\cleanup 배치 파일 사용 안내
 작성일: 2026-11-06 / 관련 작업: PLAN-20261106-01 (v1.0.2)
==============================================================

[공통]
- 모든 배치 파일은 더블클릭으로 실행합니다.
- 실행 결과는 output\ 폴더에 텍스트 파일로 저장됩니다.
- 실행 전 Docker 실행 여부와 DB 컨테이너(flask_ITMA_db) 동작 여부를
  자동으로 확인하고, 문제가 있으면 아무 작업도 하지 않고 멈춥니다.


--------------------------------------------------------------
1. 01_backup.bat  - DB 백업
--------------------------------------------------------------
 용도   : DB 전체를 backups\before_test_cleanup_날짜시간.sql 로 백업
 데이터 : 변경 없음 (읽기 전용)
 결과   : output\01_backup_result.txt (성공 여부, 파일 크기)

--------------------------------------------------------------
2. 02_inspect.bat  - 데이터 조회
--------------------------------------------------------------
 용도   : 계정, 권한 그룹, 카테고리, 자산 목록, 스펙 양식,
          테이블별 건수 조회 (inspect.sql 사용)
 데이터 : 변경 없음 (읽기 전용)
 결과   : output\inspect.txt

--------------------------------------------------------------
3. 03_delete.bat  - 테스트 데이터 삭제   [위험]
--------------------------------------------------------------
 용도   : admin 외 계정, 권한 그룹, 자산/이력, 스펙 양식,
          감사/접속/이메일 로그 전부 삭제 (delete.sql 사용)
 데이터 : 삭제됨 - 되돌릴 수 없음
 결과   : output\delete.txt (삭제 전/후 건수)

--------------------------------------------------------------
4. restore.bat  - 백업 복원   [위험]
--------------------------------------------------------------
 용도   : 가장 최근 before_test_cleanup_*.sql 백업으로 DB 전체 복원
          실행 중 YES 를 입력해야 진행됨
 데이터 : 현재 데이터를 백업 시점 내용으로 덮어씀
 결과   : output\restore.txt
 참고   : 복원 후 restart_web.bat 실행 필요

--------------------------------------------------------------
5. docker_info.bat  - 컨테이너 정보 조회
--------------------------------------------------------------
 용도   : 컨테이너 상태, compose 실행 위치, 소스 마운트 경로,
          이미지 목록 조회
 데이터 : 변경 없음
 결과   : output\docker_info.txt

--------------------------------------------------------------
6. restart_web.bat  - 웹 재시작
--------------------------------------------------------------
 용도   : web, nginx 컨테이너 재시작 (코드 수정 반영용)
          DB 는 재시작하지 않음
 데이터 : 변경 없음
 결과   : output\restart.txt (상태, 최근 로그)


--------------------------------------------------------------
7. email_reset.bat  - 이메일 SMTP 설정 초기화
--------------------------------------------------------------
 용도   : SMTP 설정 삭제 후 web 재시작 -> 기본값(빈 값, 포트 587)
          으로 다시 생성 (email_reset.sql 사용)
 데이터 : SMTP 설정 초기화 (이메일 템플릿은 유지)
 결과   : output\email_reset.txt
 참고   : 실행 후 관리자 화면에서 SMTP 정보를 다시 입력해야
          이메일 발송이 가능


- inspect.sql : 조회 쿼리 (02_inspect.bat 에서 사용)
- email_reset.sql : SMTP 설정 초기화 쿼리 (email_reset.bat 에서 사용)
- delete.sql  : 삭제 쿼리 (03_delete.bat 에서 사용)
                하나의 트랜잭션으로 실행되며, admin 계정이 없어지면
                전체 취소(롤백)됨


==============================================================
 주의 사항
==============================================================
1. 03_delete.bat 는 다시 실행하지 마세요.
   운영 데이터를 넣은 뒤 실수로 실행하면 자산과 계정이 전부 지워집니다.
   정리 작업이 끝났으므로 삭제하거나 이름 변경을 권장합니다.
   (예: 03_delete.bat.disabled)

2. restore.bat 는 2026-11-06 오전(테스트 데이터가 있던 상태)으로
   되돌립니다. 이후 입력한 운영 데이터는 사라집니다.

3. output\inspect.txt, delete.txt 에는 삭제된 계정 목록과 이메일이
   들어 있습니다. 필요 없으면 삭제해도 됩니다.


[계속 사용해도 되는 파일]
 01_backup.bat, 02_inspect.bat, docker_info.bat, restart_web.bat
