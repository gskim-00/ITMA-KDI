보안 설정

비밀번호 정책, 세션 정책, 로그인 시도 제한, IP 필터를 통합 관리합니다.

비밀번호 정책
최소 비밀번호 길이 (6-20자)
0은 유효기간 무제한
비밀번호 정책 안내
  • 최소 길이와 필수 조합(대/소문자, 숫자, 특수문자)을 설정합니다.
  • 유효기간을 0으로 두면 만료 없이 사용할 수 있습니다.
  • 정책 변경 후 신규/변경 비밀번호부터 적용됩니다.
세션 설정
비활성 시간 후 자동 로그아웃
로그인 후 최대 유지 시간
세션 설정 안내
  • 세션 타임아웃은 비활성 사용자 자동 로그아웃 기준입니다.
  • 절대 만료는 로그인 후 강제 종료되는 최대 시간입니다.
  • 동시 로그인 제한과 유지 옵션은 계정 공유 통제에 사용됩니다.
로그인 시도 제한
로그인 제한 안내
  • 지정한 시간 내 실패 누적이 기준 이상이면 잠금 처리됩니다.
  • 관리자 경고 메일을 켜면 임계치 도달 시 즉시 알림됩니다.
  • 과도하게 낮은 기준은 정상 사용자 불편을 유발할 수 있습니다.
로그인 시도 경고
동일 계정 기준, 타임 윈도우 내 실패 횟수
예: sec1@company.com, sec2@company.com
`failed_login_alert` 유형 템플릿 사용을 권장합니다.
로그인 경고 안내
  • 경고 임계치 도달 시 관리자/지정 수신자에게 즉시 메일을 보냅니다.
  • 경고 템플릿을 지정하면 변수 치환된 보안 알림이 발송됩니다.
  • 수신자 설정이 비어 있으면 알림 메일이 전송되지 않을 수 있습니다.
IP 필터링
입력 방법:
• 단일 IP: 192.168.1.1/32
• CIDR 표기법: 10.0.0.0/24
• 한 줄에 하나씩 입력
IP 필터 안내
  • 화이트리스트는 등록된 IP만 접근 허용합니다.
  • 블랙리스트는 등록된 IP만 접근 차단합니다.
  • CIDR 표기와 단일 IP를 함께 사용할 수 있습니다.
