## 1. 배경 및 목적
- 한 카테고리에 상세 스펙 폼을 여러 개 만들 수 있는데, PLAN-20261124-02에서 추가한 추가/수정 화면은 카테고리의 모든 스펙 폼 항목을 한꺼번에 표시함
- 자산마다 사용할 스펙 폼을 하나 선택하고, 선택한 폼의 항목만 입력하도록 변경

## 2. 작업 범위
- 포함
  - 추가/수정 화면 `상세 스펙` 영역에 스펙 폼 선택 상자 추가, 선택한 폼의 항목만 표시
  - 기본 선택: 저장된 값이 있는 폼(값이 가장 많은 폼) → 폼이 1개면 그 폼 → 그 외에는 `스펙 폼 선택`(항목 미표시)
  - 다른 폼으로 바꾸면 저장 시 이전 폼에 입력된 값이 삭제된다는 안내 표시
  - 저장 API에 `spec_form_id` 추가 — 선택한 폼 항목만 저장하고, 해당 자산의 다른 스펙 폼 연결 값은 삭제(이력 기록)
- 제외
  - 상세정보 모달(이미 스펙 폼 선택 + 불러오기 방식, 변경 없음)
  - 선택한 폼을 별도 컬럼으로 저장(DB 변경 없이 저장된 값으로 판단)
