## 1. 배경 및 목적
- 엑셀 일괄등록 시 품명이 빈 행은 아무 표시 없이 건너뛰어져 "추가 0건, 중복값으로 미업로드 0건"으로 표시됨 → 원인 파악이 어려움
- 요청: 모든 항목이 빈칸이어도 업로드 가능하게 하고, 자산번호(엑셀 `자산ID`)·시리얼번호가 중복일 때만 미업로드, 결과에 중복 종류별 건수 표시

## 2. 작업 범위
- 포함: `/itma/assets/upload` 업로드 규칙·응답 메시지, 업로드 결과/중복 팝업 표시
- 제외: 화면에서 직접 입력·수정하는 경로, 엑셀 템플릿 양식, DB 스키마
