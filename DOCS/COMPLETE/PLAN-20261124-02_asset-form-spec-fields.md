## 1. 배경 및 목적
- 카테고리에 상세 스펙 폼(예: 하드웨어 › 하드웨어추가: CPU, 메모리)을 추가해도 자산 추가/수정 화면(`/itma/assets/new`, `/itma/assets/<id>/edit`)에는 스펙 입력란이 없어 값을 입력·수정할 수 없음
- 자산 추가 시 카테고리를 선택하면 해당 카테고리의 스펙 폼 항목이 나타나 값을 입력하고, 수정 화면에서도 같은 방식으로 수정할 수 있게 함

## 2. 작업 범위
- 포함
  - 추가/수정 화면에 `상세 스펙` 영역 추가 — 선택한 카테고리의 활성 스펙 폼 항목을 폼별로 표시, 카테고리 변경 시 다시 표시
  - 수정 화면 조회 API(`form-data`)에 스펙 값 포함
  - 저장 API(`/assets/save`)에서 스펙 값 저장 — 현재 카테고리의 활성 스펙 폼 항목만 허용, 빈 값은 삭제, 변경 시 이력(`asset_details`) 기록
  - 상세정보 모달의 스펙 폼 입력은 기존 기능 유지(동작 확인)
- 제외
  - 스펙 폼 구조(항목 추가·삭제·이름 변경) 편집 — 관리자 '카테고리 관리'에서 수행
  - 스펙 폼에 연결되지 않은 자유 입력 스펙 행(상세정보 모달에서만 관리, 추가/수정 화면 저장 시 보존)
