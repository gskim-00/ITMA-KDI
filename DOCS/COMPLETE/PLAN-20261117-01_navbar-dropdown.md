## 1. 배경 및 목적
- 상단 메뉴의 '자산 관리', '관리화면' 버튼을 드롭다운으로 바꿔 하위 화면으로 바로 이동할 수 있게 한다
- 화면에 따라 버튼(메인화면/자산 관리/관리화면)이 나타났다 사라지던 구성을 고정된 메뉴로 정리한다

## 2. 작업 범위
- 포함
  - '자산 관리' 드롭다운: 대시보드 / 자산 목록 / 자산 추가(편집 권한자만), 현재 화면 강조
  - '관리화면' 드롭다운(admin만): 관리자 사이드바와 같은 그룹·항목, `/admin/settings#섹션`으로 이동
  - 기존 '메인화면' 버튼은 '자산 관리 > 대시보드'로 흡수, 로고(ONE ITMA)를 메인 링크로 변경
  - 관리 화면에서 드롭다운으로 이동 시 해시 변경을 감지해 해당 섹션 표시 (`admin.js`)
- 제외
  - 관리자 사이드바 자체 구조 변경, 권한 체계 변경
