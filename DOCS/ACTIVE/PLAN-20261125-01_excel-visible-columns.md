## 1. 배경 및 목적
- 지금은 엑셀 다운로드·업로드 양식의 컬럼이 서버에 고정되어 있음
  - 다운로드(선택 항목/모든 항목): 기본 16 + 장비 상세 26 + 모든 스펙 폼 항목(`상세스펙_*`) 고정 컬럼 (`_rows_to_dataframe`)
  - 업로드 템플릿: 기본 정보 16 / 장비 정보 6 / 장비 상세 3, 고정 26컬럼 (`ITMA_UPLOAD_TEMPLATE_COLUMNS`)
- 자산 목록의 '컬럼 표시 설정'에서 켜 둔 항목을 **화면 순서 그대로** 엑셀 컬럼으로 사용해, 사용자가 고른 항목만 내려받고 올릴 수 있게 함
- 엑셀 작업 전에 "현재 자산 목록에 표시된 항목이 그대로 엑셀에 반영된다"는 안내창을 보여 줌

## 2. 현재 구조 (분석 결과)
| 구분 | 위치 | 내용 |
|------|------|------|

| 확인창 | `window.confirmAction()` (`notify.js`) | 문구(텍스트)만 표시 가능 |

## 3. 작업 범위
### 포함
1. **표시 항목 전달**: 화면이 현재 표시 중인 컬럼 키를 목록 순서대로 서버에 전달 (`columns=키1,키2,...`)
   - 제외: `actions`(관리 버튼) — 화면 전용
   - 서버는 허용 목록으로 검증: 기본 컬럼 키, `detail_*`(DETAIL_COLUMN_DEFINITIONS), `spec_<id>`(활성 스펙 폼 + 조회 권한 카테고리), 사용자 정의 컬럼 키. 모르는 키는 무시, 남는 키가 없으면 400
   - `columns`가 없으면 기존 고정 양식으로 동작(이전 화면 캐시·직접 URL 호출 호환)
2. **다운로드(선택 항목/모든 항목)**: 엑셀 헤더 = 목록 컬럼 이름, 순서 = 목록 순서, 값 = 목록에 보이는 값과 같은 형식(날짜 YYYY-MM-DD, 제조년월 YYYY-MM, 운영상태 5종, 수정 일시)
3. **업로드 템플릿 다운로드**: 표시 항목으로 템플릿 생성. 자동 입력 컬럼(번호·수정 일시·수정자)은 기존처럼 회색·"자동 입력" 안내, 그룹 색상·`작성 안내` 시트 유지
   - 항목 이름이 같은 컬럼(예: 두 스펙 폼의 `CPU`)을 구분하기 위해 숨김 시트(`_columns`)에 "열 위치 → 컬럼 키" 매핑을 기록
4. **업로드**: 파일에 있는 컬럼만 반영(지금과 같이 헤더 기준)
   - 숨김 시트 `_columns`가 있으면 그 매핑을 우선 사용, 없으면 기존 헤더 별칭(이전 양식 호환)으로 인식
   - **스펙 컬럼 저장 추가**: `spec_<id>` 컬럼 값을 해당 자산 카테고리의 스펙 폼 항목일 때만 저장(다른 카테고리 항목 값은 무시)
   - **사용자 정의 컬럼 저장 추가**: 컬럼 관리 권한(`can_manage_columns`)이 있을 때만 저장, 권한이 없으면 해당 컬럼 무시 + 결과 메시지에 안내
5. **안내창**: 아래 4개 동작 전에 공통 안내 모달 표시, '계속'을 눌러야 진행
   - 다운로드 › 선택 항목 / 모든 항목, 업로드 모달 › 템플릿 다운로드 / 업로드
   - 내용: "현재 자산 목록에 표시된 항목 N개가 목록 순서 그대로 엑셀에 반영됩니다." + 항목 이름 목록 + "항목은 목록의 '컬럼 표시 설정'에서 바꿀 수 있습니다."
   - 업로드일 때 추가 문구: "파일에 있는 항목만 등록되며, 목록에 없는 항목은 빈 값으로 등록됩니다."
   - 표시 항목이 기본 필수 컬럼(번호·카테고리·자산번호)뿐이어도 진행 가능
### 제외
- 다운로드 대상 **행** 기준 변경(선택 항목 = 체크한 자산, 모든 항목 = 권한 범위 전체 자산 — 현행 유지. 아래 9번 확인 사항 참고)
- 업로드로 기존 자산 수정(현행: 신규 등록만)
- 목록에 없는 장비 상세 항목(장비상태·유지보수·인증 등 17개)의 엑셀 입출력 — 목록에 표시할 수 없는 항목이므로 이번 방식에서는 내려받을 수 없게 됨(6번 위험 요소)

## 7. 위험 요소 및 복구 방법
- **다운로드 컬럼 축소**: 지금 전체 다운로드에 들어 있는 장비 상세 17개 항목(장비상태·납품업체·유지보수·구매일시·내구연한·인증 등)과 목록 미표시 스펙 항목은 더 이상 내려받을 수 없음 → 백업·보고용으로 필요한지 확인 필요(9번)
- **같은 이름 컬럼**: 스펙 항목명이 겹치면 엑셀 헤더가 같아짐 → 템플릿은 `_columns` 매핑으로 구분. 다운로드 파일을 수정해 다시 올리는 경우에도 같은 매핑 시트를 넣어 구분
- **사용자별 설정**: 표시 항목은 브라우저별 저장이라 같은 계정이라도 PC마다 결과가 다를 수 있음 → 안내창에 항목 목록을 보여 확인하게 함
- **URL 길이**: 선택 다운로드는 `ids`와 `columns`를 GET으로 전달 → 선택 수가 매우 많으면 길어질 수 있음. 현행과 같은 방식 유지, 문제 시 POST 전환
- 복구: 이번 커밋 되돌림(`git revert`). `columns` 없는 요청은 기존 양식으로 동작하므로 화면만 되돌려도 기존 동작 복원

## 9. 착수 전 확인 사항 (사용자 결정 필요)
1. **다운로드 행 범위** — '모든 항목'은 지금처럼 권한 범위 전체 자산으로 둘지, 목록에 보이는 필터·검색 결과만 내려받을지 (계획 기본값: 현행 유지)
2. **번호 컬럼** — 목록의 '번호'(조회 결과 순번)를 엑셀에도 넣을지 (계획 기본값: 목록에 켜져 있으면 포함)

4. **업로드 시 스펙·사용자 정의 컬럼 저장** — 이번 범위에 포함할지 (계획 기본값: 포함)
