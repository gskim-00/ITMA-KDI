## 1. 배경 및 목적
- 엑셀 다운로드 컬럼이 서버에 고정되어 있고, 이전 버전·삭제된 스펙 폼에서 생긴 `상세스펙_*` 컬럼까지 계속 내려받아짐
- 다운로드할 **자산**(선택 항목/모든 항목)을 고른 뒤 안내창에서 **항목 구성**(사용자 지정/기본)을 고를 수 있게 함
- 상세 스펙·사용자 정의 컬럼은 **현재 서버에 있는 것만**, 값은 **자산 목록에 보이는 것과 같은 값만** 엑셀에 나오게 함
- 업로드 템플릿은 기본 형식으로 고정하고, 업로드 전에 안내창을 표시

## 4. 작업 범위
### 포함
#### A. 다운로드 흐름 변경
1. 다운로드 버튼 › **선택 항목** / **모든 항목** 은 지금처럼 다운로드할 자산을 정함(선택 항목은 체크한 자산이 없으면 지금처럼 안내)
2. 이어서 **엑셀 다운로드 안내창**(신규 모달) 표시
   - 안내: "엑셀에는 자산 목록과 같은 항목·값이 반영됩니다." + 대상 자산 건수(선택 N건 / 전체)
   - 항목 구성 선택(라디오)
     - **사용자 지정 항목**: 자산 목록 '컬럼 표시 설정'에서 켜 둔 항목을 목록 순서 그대로(관리 버튼 컬럼 제외). 안내창에 항목 이름 목록 표시
     - **기본 항목**: 업로드 템플릿과 같은 기본 형식 + 현재 서버의 상세 스펙 폼 항목 + 현재 사용자 정의 컬럼(5번 확인 사항)
   - [다운로드] / [취소]
3. 서버: `columns` 파라미터(컬럼 키 목록) 또는 `preset=basic`으로 컬럼 구성
   - 허용 키만 사용: 기본 컬럼, `detail_*`, `spec_<항목id>`(활성 스펙 폼 + 조회 권한 카테고리), 현재 사용자 정의 컬럼 키. 모르는·삭제된 키는 무시, 남는 키가 없으면 400
   - 두 파라미터가 모두 없으면 `preset=basic`과 같게 동작(직접 URL 호출 호환)
#### B. 엑셀 값 규칙
1. **번호**: 엑셀 행 순서대로 1부터 다시 매김 (사용자 지정 항목에서 '번호'가 꺼져 있으면 넣지 않음, 기본 항목에는 항상 포함)
2. **헤더·값 형식**: 자산 목록과 같은 이름(카테고리·자산번호·운영상태 등 현재 화면 이름), 날짜 YYYY-MM-DD, 제조년월 YYYY-MM, 수정 일시 YYYY-MM-DD HH:MM, 운영상태 5종
3. **상세 스펙 컬럼**: 현재 활성 스펙 폼의 항목만, 헤더 = 항목 이름(목록과 같음). 값 = 그 항목에 연결된 값만(`source_form_item_id`) — 자유 입력 스펙 행·이전 버전 값(`cpu_spec` 등)·삭제된 폼의 값은 나오지 않음
4. **사용자 정의 컬럼**: 현재 `itma_custom_columns`에 있는 컬럼만, 값은 `itma_custom_column_values`
5. **같은 이름 컬럼 구분**: 스펙 항목 이름이 겹칠 수 있으므로(예: 두 폼의 `CPU`) 숨김 시트 `_columns`에 "열 위치 → 컬럼 키"를 기록. 화면 헤더는 목록과 같게 유지
#### C. 업로드 템플릿 (기본 형식 고정)
- 지금 템플릿 형식 유지: 기본 정보 / 장비 정보 6 / 장비 상세 3, 자동 입력 컬럼(번호·수정 일시·수정자) 회색, `작성 안내` 시트
- 상세 스펙·사용자 정의 컬럼은 템플릿에 넣지 않음
#### D. 업로드
1. 업로드 실행 전 **엑셀 업로드 안내창** 표시: "엑셀 파일의 내용이 자산 목록에 그대로 등록됩니다. 기본 형식 항목(기본 정보·장비 정보·장비 상세)과 현재 서버에 있는 상세 스펙·사용자 정의 컬럼만 반영되고, 삭제되었거나 알 수 없는 컬럼은 무시됩니다." [업로드] / [취소]
2. 인식 규칙
   - 기본·장비 정보: 현행(헤더 이름 + 이전 양식 별칭)
   - 상세 스펙·사용자 정의 컬럼: 다운로드 파일의 `_columns` 시트가 있으면 키로 인식, 없으면 헤더 이름으로 현재 항목과 매칭(이름이 겹치면 해당 자산 카테고리의 항목 우선). 현재 서버에 없는 컬럼(삭제·이전 버전 `상세스펙_*` 등)은 무시
   - 상세 스펙 값은 자산 카테고리의 스펙 폼 항목일 때만 저장, 사용자 정의 컬럼은 컬럼 관리 권한(`can_manage_columns`)이 있을 때만 저장(없으면 무시 + 결과 메시지 안내)
   - 번호·수정 일시·수정자는 무시(현행)
3. 신규 등록만(현행 유지), 중복 검사 현행 유지
### 제외
- 업로드로 기존 자산 수정
- DB에 남아 있는 이전 버전·삭제된 폼의 스펙 값 삭제(엑셀에서만 제외, 데이터는 보존 — 상세정보 모달의 자유 입력 행으로 계속 보임)
- 목록에 없는 장비 상세 17개 항목(장비상태·납품업체·유지보수·구매일시·내구연한·인증 등)의 엑셀 입출력 — 기본 항목에서도 빠짐(7번 위험 요소, 9번 확인 사항)

## 8. 위험 요소 및 복구 방법
- **다운로드 컬럼 변화**: 지금 다운로드에 있는 장비 상세 17개 항목과 이전 헤더(`구분`·`자산ID`·`사용여부`·`상세_*`)가 바뀌거나 빠짐 → 기존 다운로드 파일을 다른 곳에서 쓰고 있다면 영향. 업로드는 이전 헤더도 계속 인식
- **이전 스펙 값 미표시**: 스펙 폼에 연결되지 않은 값(이전 버전·삭제된 폼·자유 입력)은 엑셀에 나오지 않음 — 요청 사항이며 DB 데이터는 보존
- **같은 이름 컬럼**: `_columns` 시트로 구분. 사용자가 시트를 지운 파일은 이름으로 매칭(카테고리 우선)
- **사용자별 설정**: 사용자 지정 항목은 브라우저별 저장 → 안내창에 항목 목록을 보여 확인하게 함
- **URL 길이**: 선택 다운로드는 `ids`·`columns`를 GET으로 전달 → 선택이 매우 많으면 POST로 전환
- 복구: 이번 커밋 되돌림(`git revert`)

1. **기본 정보 개수** — 지금 템플릿의 기본 정보는 **17개**(번호·카테고리·사업장·자산번호·제조사·품명·입고일·입고 메모·출고일·출고 메모·보관 위치·상세 메모·담당자·운영상태·제조년월·수정 일시·수정자)입니다. 자산 목록의 '기본 정보' 그룹 18개에는 화면 전용 '관리'(상세정보/수정 버튼) 컬럼이 들어 있습니다. 17개로 진행해도 되는지, 추가할 항목이 있는지
2. **'기본 항목' 다운로드 구성** — 기본 형식(17+6+3) + 현재 상세 스펙 폼 항목 전체 + 현재 사용자 정의 컬럼으로 할지 (계획 기본값). 스펙 항목은 목록 표시 여부와 관계없이 현재 활성 폼의 항목 전체
3. **장비 상세 17개 항목**(장비상태·납품업체·유지보수·구매일시·내구연한·인증 등, 상세정보 모달 입력 항목) — 엑셀에서 빠져도 되는지 (계획 기본값: 제외)

## 10. 검증 방법
