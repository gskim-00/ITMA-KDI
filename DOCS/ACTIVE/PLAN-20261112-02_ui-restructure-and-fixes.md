## 1. 배경 및 목적
- 메인 화면을 자산 현황 대시보드로 바꾸고, 자산 관리는 별도 페이지로 분리한다
- 목록에서 자유롭게 수정되던 방식을 막고, 추가/수정 전용 페이지에서 저장 버튼으로만 수정한다
- 사업장(대전, 연구소, 구미 등)별 조회, 목록 표시 개선, 확인된 버그 3건을 수정한다

## 2. 작업 범위 (사용자 확정 사항 포함)
### 화면 구성
- `/itma/` → 대시보드(자산 현황, 기존 대시보드 모달 내용) 메인 화면
- `/itma/assets/page` → 자산 관리(목록) 페이지, 상단 메뉴로 이동
### 자산 추가/수정
- 목록은 읽기 전용(칸 직접 입력 수정 제거)
- 추가/수정 전용 페이지: **기본 정보 + 장비 정보**(그룹·사용자·직급·네트워크 구분·IP/Subnet·Mac·장비명·OS/Version·Serial) + 사용자 정의 컬럼, 저장 버튼
- 목록의 일괄 수정·엑셀 업로드·선택 삭제 버튼은 **유지**
### 사업장별 조회
- 자산에 **사업장(site) 항목 신규 추가**, 목록 상단에서 사업장별 조회, 추가/수정 페이지·엑셀 템플릿/업로드·다운로드에 반영
### 자산 목록
1. 필터·정렬 결과 기준으로 순번을 1부터 다시 표시 (자산 고유 번호는 자산번호로 구분)
2. 운영 상태를 토글 → 선택식 **정상/사용/미사용/교체/폐기**, 기존 O→사용, X→미사용 변환
3. 자산번호 클릭 대신 행마다 '상세정보' 버튼으로 상세 조회/수정
### 버그
- 세션 타임아웃 설정이 반영되지 않는 현상
- 변경이력 → 삭제 이력 복원 시 자산 번호가 다르게 표시·복원되는 현상
- 사용자 정의 컬럼을 user 권한 계정이 수정할 수 있는 현상
### 제외
- 대시보드 새 창(공개 토큰) 방식, 권한 체계 자체 변경
